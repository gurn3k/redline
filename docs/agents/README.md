# For agents working in this repo

- Issues live as local markdown files under `.scratch/`. See
  `docs/agents/issue-tracker.md`.
- Decisions live in `docs/adr/`, one file per decision, numbered
  (`0001-...`, `0002-...`). Read the relevant ones before changing anything
  they cover.
- Settled project-wide rules and scope live in `CLAUDE.md`.
